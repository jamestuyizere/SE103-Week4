What a pull request asks teammates to do:
A pull request asks teammates to review changes before they are added to the main branch. It gives them a chance to check the work, leave feedback, and approve the changes.

Why branches and pull requests are used together:
Branches allow developers to work on changes separately from the main project. Pull requests are then used to review those branch changes before merging them into main.
